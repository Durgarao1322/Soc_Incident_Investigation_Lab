# SOC Incident Investigation Lab

## Overview

This project demonstrates a SOC incident investigation using Splunk SIEM, Windows Event Logs, Sysmon, and VMware.

## Tools Used

* Splunk Enterprise
* Windows 10
* Sysmon
* Splunk Universal Forwarder
* VMware Workstation

## Investigation Activities

* Failed Login Analysis (Event ID 4625)
* Successful Login Analysis (Event ID 4624)
* User Account Creation Detection (Event ID 4720)
* Process Activity Monitoring

## Deliverables

* Incident Timeline
* IOC List
* Incident Report
* Screenshots
